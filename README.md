# 📚 DSA in C++

A structured collection of Data Structures and Algorithms problems implemented in C++. This repository focuses on building strong problem-solving skills, understanding algorithmic concepts, and preparing for technical interviews.

## 💻 Language
C++

## ⚙️ How to Run a Solution

Make sure you have a C++ compiler installed, such as GCC.

## Compile a solution:

```text
g++ solution.cpp -o solution
```

## Run it on Windows:

```text
solution.exe
```
## Run it on Linux or macOS:

```text
./solution
```
